# Portfolio Site

A modern, professional portfolio website built with Next.js and Tailwind CSS. This site serves as a dynamic showcase of my skills, projects, and professional journey.

## Features

- **Modern Design**: Clean, responsive UI with smooth animations.
- **Project Showcase**: Dedicated pages for detailed project presentations.
- **Tech Stack**: Built with Next.js (App Router) and styled with Tailwind CSS.
- **Performance**: Optimized for speed and SEO.

## Getting Started

### Prerequisites

- Node.js (v20.19.0 || v22.13.0 || >=24)
- npm (v11.7.0)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd portfolio-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

### Build

Build the application for production:

```bash
npm run build
```

### Run

Run the production build:

```bash
npm run start
```
